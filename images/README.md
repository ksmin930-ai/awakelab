# 📸 AWAKE LAB 공간 갤러리 사진 교체 가이드

이 폴더(`images/`)에 실제 어웨이크랩 합주실 사진 파일을 넣어주시면, 사이트 갤러리에 자동으로 실제 사진이 반영됩니다.

---

## 📁 권장 파일명 및 매칭 안내

| 파일명 | 추천 사진 대상 | 권장 해상도 / 비율 |
| :--- | :--- | :--- |
| `room-main.jpg` | 합주실 메인 전경 (악기 전체가 한눈에 보이는 샷) | 16:9 (1920x1080 또는 1200x800) |
| `drum.jpg` | 드럼 셋 (Pearl / Zildjian 심벌 근접 또는 정면샷) | 16:9 또는 4:3 |
| `keys.jpg` | 건반 및 신디사이저 (Kurzweil 88건반 정면/측면샷) | 16:9 또는 4:3 |
| `amp-guitar.jpg` | 기타 진공관 앰프 (Marshall / Fender 등) | 16:9 또는 4:3 |
| `amp-bass.jpg` | 베이스 앰프 (Ampeg 등) | 16:9 또는 4:3 |
| `vocal.jpg` | 보컬 마이크 및 스피커 모니터 | 16:9 또는 4:3 |
| `console.jpg` | 믹서 콘솔 및 음향 장비 랙 | 16:9 또는 4:3 |
| `lounge.jpg` | 휴게 쇼파 및 편의시설 (에어컨/공기청정기) | 16:9 또는 4:3 |
| `room-mood.jpg` | 무대 조명을 켠 분위기 있는 감성 샷 | 16:9 (1920x1080) |

---

## 💡 팁
- 파일 포맷은 `.jpg`, `.jpeg`, `.png`, `.webp` 모두 지원됩니다.
- 모바일에서 빠르게 로딩되도록 사진당 용량은 **1MB~3MB 내외**로 압축하여 넣으시는 것을 추천합니다.
- 사진 파일이 추가되면 `index.html` 내의 `GALLERY_ITEMS` 배열에서 해당 파일명(`images/room-main.jpg` 등)으로 설정되어 우선 로드됩니다.
